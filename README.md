# Tezca-china

Ứng dụng học tiếng Trung với flashcard, quiz ngữ cảnh, ngữ pháp HSK, chat AI và luyện viết.

## Tính năng

- **Flashcard SRS** — ôn từ vựng theo thuật toán spaced repetition
- **Quiz ngữ cảnh** — câu hỏi theo tình huống giao tiếp đời sống
- **Ngữ pháp HSK** — bài học và quiz ngữ pháp
- **AI Chat** — luyện hội thoại với AI
- **Tra cứu từ vựng** — tìm kiếm trong kho từ

## Chạy dự án

```bash
npm install
npm run dev
```

## Công nghệ

React + Vite
