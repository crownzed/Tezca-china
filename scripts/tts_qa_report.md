- **Pin heteronym readings**: for the flagged chars, store a per-text pinyin override and pass it to the engine (SSML `<phoneme>` or a pinyin-driven TTS) instead of raw hanzi.
- **Normalize before synthesis**: route text through `normalize_for_tts()` so digits/symbols from custom vocab never reach the engine raw.
- **Enable STT in CI**: set `OPENAI_API_KEY` and run with `--stt openai` to turn the accuracy score from a proxy into a measured diff.
